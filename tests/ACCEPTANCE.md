# ตรวจรับบนฐานข้อมูลทดสอบ
- เปิดเว็บใหม่ไม่มีหน้าล็อกอิน กรอกรหัส 001 แล้วค้นหาได้ รหัสไม่มีอยู่ได้ 404 และไม่ค้างข้อมูลคนก่อน
- ผู้ดูแลต้อง login; POST employee/rates/publish โดยไม่มีสิทธิ์ต้องได้ 401 และไม่มี CSRF ต้องได้ 403; GET เปลี่ยนข้อมูลได้ 405
- เพิ่มสมาชิก 001/002 ตั้ง emoji และรูป ทดสอบ thumbnail และ fallback
- ใส่กะ E/L/N ให้ 001 เดือนหนึ่ง ยอด 260 บาท คน 002 ที่กะเดียวกันวันเดียวกันปรากฏเป็นเพื่อน แต่วันหยุดไม่แสดง
- นำเข้ารูปที่มีเส้นและหัวครบเดือน ตรวจทุกช่องก่อนเผยแพร่ UNKNOWN ต้องแก้ก่อน
- ส่งรหัสที่ไม่มีสมาชิก/วันที่ผิด/รายการซ้ำต้องถูกปฏิเสธ และตารางเดิมไม่ถูกลบ
- เผยแพร่ซ้ำไม่สร้างกะซ้ำ ร่าง revision เก่าถูกปฏิเสธด้วย 409
- สมาชิกไม่มีเมนูนำเข้าหรือวันอบรม เปิดหลายคนไม่มี request OCR/polling
- PWA ติดตั้งบน Android/iPhone ผ่าน HTTPS ของโฮสต์จริง เปิดออฟไลน์ได้หน้าแจ้งสถานะ ไม่มีค่ากะหรือชื่อค้างใน cache
- ปิดบัญชีสมาชิกแล้วค้นหาไม่ได้ รูปสมาชิกปิดใช้ได้ 404
- หลัง logout เข้า admin API ไม่ได้และตรวจ cache ไม่มีข้อมูลสมาชิก
