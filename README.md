# ShiftTrack ใหม่

PHP 8.3, PDO MySQL, Bootstrap 5.3.8, Bootstrap Icons 1.13.1 และ JavaScript ไม่มีขั้นตอน build บนโฮสต์

สมาชิกเปิดเว็บทันที ใส่รหัสพนักงานดูตาราง ค่ากะ และเพื่อนร่วมกะ ไม่ต้องสมัคร/เข้าสู่ระบบ ไม่มีวันอบรม รหัสพนักงานใช้ค้นหา ไม่ใช่การยืนยันตัวตน ใครมีลิงก์และรหัสอาจดูข้อมูลได้

เจ้าของใช้ admin.php จัดการสมาชิก รูปบุคคล อัตรากะ และตารางกลาง อ่านรูปด้วย Tesseract.js บนเครื่องเจ้าของ ตรวจผลแล้วเผยแพร่แทนตารางทั้งเดือน สมาชิกไม่มีสิทธิ์แก้ข้อมูล

## เริ่มใช้งาน
ดู DEPLOY_BYETHOST.md ใช้ฐานข้อมูลใหม่และ schema.sql ไม่ย้ายข้อมูลรุ่นเดิม

อัตราเริ่มต้นตามเจ้าของ: E=80, L=80, N=100 บาท กะอื่น 0 บาท เป็นค่ากะต่อรายการรายวัน ยอดรวมตามเดือนปฏิทิน การเปลี่ยนเรตมีผลกับทุกเดือนที่เปิดดู

สมาชิกในกะเดียวกันหมายถึงวันที่เดียวกันและรหัส D/E/L/N เดียวกัน กะ N ผูกกับวันเริ่มกะ ไม่กำหนดเวลาเริ่ม/จบเนื่องจากยังไม่ได้รับเวลาใช้งานจริง

รูปตารางต้องมีเส้นชัด หัววัน 1–วันสุดท้ายครบ และคอลัมน์ ID รองรับ OCR รหัสตัวเลข การค้นหาปกติรองรับรหัสตัวอักษรด้วย ชื่อ OCR ใช้ประกอบการอ่าน แต่ชื่อเผยแพร่ใช้ทะเบียนสมาชิกที่เจ้าของกรอกเพื่อไม่เดาชื่อผิด สามารถสร้างตารางว่างและแก้ทุกช่องได้

PWA ต้องออนไลน์เพื่ออ่านข้อมูล เก็บ cache เฉพาะ assets และหน้า offline ไม่เก็บตาราง รูปสมาชิก หรือค่ากะใน localStorage/IndexedDB ไม่มี polling

## พัฒนาในเครื่อง
เปิดโฟลเดอร์นี้ด้วย VS Code คัดลอก private/config.example.php เป็น private/config.php ใส่ฐานข้อมูลว่างที่สร้างใหม่และ password hash ตั้ง secure_cookies=false เฉพาะ localhost

รัน `php -S 127.0.0.1:8091 -t public` และเปิด http://127.0.0.1:8091

ตรวจ syntax: `php -l public/api.php` และไฟล์ PHP อื่น ตรวจ workflow ตาม tests/ACCEPTANCE.md

## รุ่นที่ใช้งานปัจจุบัน
- เว็บหลัก: https://shifttrackteam.byethost9.com/
- ธีมน้ำเงิน–ทอง ฟอนต์ Noto Sans Thai โหมดสว่าง/มืด และแอนิเมชันที่รองรับการลดการเคลื่อนไหว
- สมาชิกใช้รูปบุคคลหรืออักษรย่อ ไม่มีช่องอีโมจิ
- แสดงวันทำงาน วันหยุด จำนวนแต่ละกะ สถานะวันนี้ และเวลาเผยแพร่ตาราง
- จำเฉพาะรหัสพนักงานและเดือนล่าสุดในเบราว์เซอร์ หลังค้นหาสำเร็จ ไม่เก็บตารางหรือค่ากะไว้ในเครื่อง
- GitHub เก็บเฉพาะซอร์สและตัวอย่างการตั้งค่า ไม่รวมฐานข้อมูลจริง ภาพทดสอบ รหัสผ่าน logs และชุด deploy

## โฟลเดอร์หลัก
ใช้โฟลเดอร์นี้เป็น checkout สำหรับพัฒนาและอัปเดต GitHub เครื่องมือ PHP/MariaDB ในเครื่องอยู่ที่โฟลเดอร์พี่น้อง `.shifttrack-runtime` และไม่รวมใน repository
